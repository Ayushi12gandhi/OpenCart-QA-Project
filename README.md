# OpenCart QA Project

This repository contains a complete Manual Testing project for the OpenCart e-commerce application.

- Requirement Analysis
- Test Plan
- Test Scenarios
- Test Cases
- Bug Reports
- Requirement Traceability Matrix (RTM)
